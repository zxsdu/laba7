# Лабораторна робота №7. Читання та запис даних у файли (Варіант 5)

Програма працює зі списком книг у файлі `books.txt` (формат `Автор,Назва,Рік`).

| Файл | Призначення |
|------|-------------|
| `lab7.py` | основна програма |
| `test_lab7.py` | unit-тести (18 тестів) |
| `books.txt` | вхідні дані |

## Запуск

```bash
python lab7.py
python -m unittest test_lab7 -v
```

Програма створює файл `books_by_year.txt` з книгами вказаного року та видаляє книги автора
(за замовчуванням «Шевченко») з файлу, який вкаже користувач.
